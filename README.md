# RoughSpindle

RoughSpindle is a real-time, cloud-agnostic system for autonomous data processing, leveraging auto-scaling clusters for scalable, fault-tolerant module execution.

RoughSpindle is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughSpindle.git`
2. `cd RoughSpindle`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
